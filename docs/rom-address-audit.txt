ROM address checks: Third Strike 990512 (sfiii3nr1)

Stock sound tables:
  Instrument banks  06788000
  Sample table      0678C000
  Sequence table    0678F000
  Sequence count    3251

The stock ROM's own code contains these table addresses. Sound data ends at
067D1F6B. The allocation regions 067D1F6B..067FFFE0 and 06E60000..06FFFFF0
are zero-filled in the original ROM.

The example export reached the attract screen after 1200 offscreen FBNeo
frames. The core confirmed that it loaded the patched archive. This verifies
boot, not playback of the replacement music.

FBNeo direct archive loading identifies the game from the ZIP basename.

a checksum warning.
